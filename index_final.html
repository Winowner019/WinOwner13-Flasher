Win Owner 13 — ESP Flasher

Веб-флешер для ESP32 • телефон / ПК • ST7789 Touch

1. Конфигурация платы

ESP32-WROOM-32: ST7789 240×320, Touch XPT2046. Дисплейные пины — как в XD Service.

2. Подключение

ESP32 не подключён

Подключай плату USB-кабелем с передачей данных. В браузере появится окно выбора USB/Serial-порта.

3. Прошивка

Этот файл прошивается с адреса 0x0000. Используй именно merged/factory BIN, а не обычный app .ino.bin.

4. Лог

Win Owner 13 Flasher готов.\nВыбери плату и подключи ESP32.

5. Схема — ESP32-WROOM-32 + ST7789 Touch

6. Схема — ESP32-S3 + ST7789 Touch

Для ESP32-S3 я намеренно не выдумываю GPIO: у разных S3-плат распиновка дисплея/тача отличается. Если пришлёшь модель платы — в сайт можно добавить точную схему.

5. Схемы подключения

WOKWI STYLE

Наглядные схемы с цветными проводами. Нажми нужную схему — остальные скроются.

ESP32-WROOM-32 + ST7789 + XPT2046
GPIO 18/19/23 — SPITouch: 25/26/27/32
ESP32-WROOM-32 + RC522 RFID (SPI)

В этой отдельной схеме RC522 использует SPI. GPIO 16 выбран для RST и GPIO 33 для CS, чтобы не занимать линии тача.
